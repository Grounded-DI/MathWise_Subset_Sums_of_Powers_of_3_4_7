# A Fixed Covering Certificate for Subset Sums of Powers of 3, 4, and 7

## Overview

This repository contains a fixed-case theorem note and replayable computational certificate for

```text
[582, ∞) ⊆ A₁({3,4,7}).
```

Here `A₁({3,4,7})` is the set of subset sums of distinct positive powers generated by 3, 4, and 7. The record combines a finite initial-interval certificate, an interval-overlap propagation argument, and full paired modular certificates for the weighted-gap cases.

The result is deliberately narrow: `D = {3,4,7}` and `k = 1` only.

## What the record demonstrates

The finite verifier enumerates subset sums from

```text
3, 4, 7, 9, 16, 27, 49, 64, 81, 243, 256, 343, 729, 1024, 2187
```

It records:

```text
[582,4460] is contained in the subset-sum set
total subset sums generated = 4969
STATUS: PASS
```

The weighted-gap verifier then reconstructs three bounded, full paired modular systems:

- Case A: baseline `3^r`, with **1,361,889** residue-admissible systems;
- Case B: baseline `4^s`, with **255,938** residue-admissible systems; and
- Case C: baseline `7^q`, with **1,501,666** residue-admissible systems.

Across the three cases, **3,119,493** residue-admissible systems are checked. The recorded replay ends with:

```text
Case A final survivors: 0
Case B final survivors: 0
Case C final survivors: 0
Weighted Gap Lemma: PASS
Global overlap inequality: PASS
Fixed theorem chain: PASS
FINAL STATUS: PASS — WEIGHTED_GAP_PROVED
```

The replay also records that the three difference-only shadow examples are eliminated by the corresponding full paired tests. The certificate does not rely on a least-larger condition.

```bash

```

The expected terminal status is **PASS** for both scripts. The logs in this repository preserve a prior successful run; rerunning the scripts is the fresh local check.

## Technical significance

The package makes the proof path inspectable: a finite coverage interval is checked directly, the propagation condition is reduced to weighted next-power gaps, and the dangerous bounded systems are tested with full paired congruence conditions rather than difference-only shadows. Code, tables, source, paper, and replay logs are kept together so a reviewer can reconstruct the recorded result.

## Scope and limitations

The paper and certificate support only the fixed case `D = {3,4,7}`, `k = 1`. They do not claim:

- that `582` is the least possible endpoint;
- a result for another generating set;
- a result for `k ≠ 1`;
- a density, asymptotic, or classification theorem; or
- independent third-party acceptance.

The local replay verifies the included finite computations and certificate logic. It is not an independent mathematical review, and it does not by itself establish correctness of every explanatory statement in the paper. External independent verification remains **UNVERIFIED**.
